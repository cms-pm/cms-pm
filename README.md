### Chris Slothouber

Embedded systems engineer exploring how far AI coding agents can be trusted
on real firmware, and what evidence it takes to trust them. Author of
*AI-Assisted Embedded Development* (Chapter 1 early release, October 2026).

**Flagship projects**

- [**ai-dev-governance**](https://github.com/cms-pm/ai-dev-governance): a
  versioned rulebook and toolkit for building software with AI agents without
  lowering the engineering bar. Planning, evidence and acceptance gates the
  agent can't grade itself against, with an embedded profile.
- [**brontes-probe-mcp**](https://github.com/cms-pm/brontes-probe-mcp): an MCP
  server that lets AI assistants drive a debug probe: flash, halt, read
  memory, and stream ITM/SWO trace on Cortex-M targets.
- [**astaire**](https://github.com/cms-pm/astaire): a SQLite-backed knowledge
  store that gives agents cheap, token-budgeted context instead of raw file
  reads.

**Also**

- [zydeco-profiler-mcp](https://github.com/cms-pm/zydeco-profiler-mcp):
  evidence-first A/B benchmarking for embedded code size and cycles.
- [kv4-edge-inference](https://github.com/cms-pm/kv4-edge-inference):
  reproduction package for a study of 4-bit KV-cache quantization on a 4 GB
  GPU ([paper](https://ssrn.com/abstract=6941538)).
